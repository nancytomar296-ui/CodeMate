DEBUGGING GUIDE

Learn to debug your code

Don't randomly change your code. Follow a simple process to find, understand and fix the real problem.

01

Read the complete error

First read the complete error message shown by your browser or development environment. Don't ignore the error type, message or location.

ReferenceError: userName is not defined
at script.js:5
02

Find the file and line

Error messages often tell you the file and line where the problem occurred. For example, script.js:5 means the problem was reported in script.js around line 5.

File: script.js
Line: 5
03

Check the code carefully

Look at the line mentioned in the error. Check variable names, spelling, brackets, quotes, functions and values.

console.log(userName);

const userName = "Nancy";
04

Make one change at a time

Avoid changing many things at once. Make one small change, run the project and check what happens. This makes debugging much easier.

🔎 Find the problem
✏️ Make one change
▶ Run the project
05

Test the fix

Run your project again after making the change. If the error disappears and the feature works correctly, your fix was successful.

✓ Error fixed
Code is running correctly.
💡

Remember common errors

These are some common problems beginners may encounter:

ReferenceError → variable not found
SyntaxError → invalid code structure
TypeError → incorrect value usage
404 → file or page not found
CORS → cross-origin request blocked
