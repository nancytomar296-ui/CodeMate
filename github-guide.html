Put your project on GitHub

Learn how to create a repository, upload your project files and save your code online.

01

Create a GitHub repository

A repository is a place on GitHub where your project files and code are stored.

📝 Description

02

Upload your project files

Upload the files that belong to your website. For example, HTML, CSS, JavaScript and images.

🎨 style.css
⚙️ script.js
📁 images
03

Commit your changes

A commit saves the current version of your project to the repository. You can think of it as a saved version of your work.

📝 Add commit message
💾 Save changes
✓ Commit changes
04

Check your repository

After committing, your files will appear inside the repository. You can open them anytime from your GitHub account.

✓ index.html
✓ style.css
✓ script.js
✓ Project uploaded
05

Your code is online

Your project is now stored safely in GitHub. You can share the repository link with teachers, friends or recruiters.
